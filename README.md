# KaMo

> Building an operating system from the ground up.

**By Nicholas Klapal & Moosa Awais**

KaMo is an open-source operating system being built from scratch in **C** and **x86 Assembly**.

Our goal is to create an operating system that is functional, understandable, and educational. By focusing on clean architecture and readable code, KaMo aims to make low-level systems programming more approachable for students, developers, and anyone curious about how computers work.

---

## Vision

Modern operating systems are incredibly powerful, but their complexity often makes them difficult to understand.

KaMo is built with a different mindset: an operating system should not only be usable, but also teach.

We aim to create a platform where people can explore concepts like kernels, memory management, hardware interaction, and computer architecture through hands-on experience.

---

## Current Status

KaMo is currently in early development and is being rebuilt from the ground up.

Our focus is establishing a strong foundation before expanding into more advanced features.
